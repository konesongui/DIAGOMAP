🚀 ÉTAPES D'INSTALLATION
─────────────────────────────────────────────────────────────────────────────────

ÉTAPE 1 : Créer la base de données
☐ Accédez à : http://localhost/diagoma/install_qrcode.php
☐ Cliquez sur "Installer"
☐ Vérifiez le message "✅ Installation réussie !"
☐ La table 'staff_attendance_qr' a été créée

ÉTAPE 2 : Ajouter les routes
☐ Ouvrez le fichier : application/config/routes.php
☐ Ajoutez à la fin du fichier :

$route['admin/qrattendance/display'] = 'admin/Qrattendance/display_qr';
$route['admin/qrattendance/scan'] = 'admin/Qrattendance/scan_page';
$route['admin/qrattendance/process'] = 'admin/Qrattendance/process_scan';
$route['admin/qrattendance/today'] = 'admin/Qrattendance/today_attendance';
$route['admin/qrattendance/report'] = 'admin/Qrattendance/attendance_report';

☐ Sauvegardez le fichier

ÉTAPE 3 : Sécuriser l'installation
☐ Supprimez le fichier : install_qrcode.php
  (Pour des raisons de sécurité - ne pas laisser ce fichier accessible)

ÉTAPE 4 : Vérifier l'intégration RH
☐ Accédez à : http://localhost/diagoma/admin/admin/rh
☐ Vous devez voir la section "Présence et badges"
☐ Vous devez voir 3 nouvelles cartes :
    ✓ Afficher QR Code
    ✓ Présences du jour
    ✓ Rapport Présence

📱 FLUX UTILISATEUR COMPLET
─────────────────────────────────────────────────────────────────────────────────

Admin du matin :
  1. Ouvre http://localhost/diagoma/admin/admin/rh
  2. Clique sur "Afficher QR Code"
  3. Affiche le code sur un écran/affichage à l'entrée
  4. Laisse tourner toute la journée

Employé à l'arrivée :
  1. Scanne le QR code avec son téléphone
  2. Entre son ID employé (ex: EMP001)
  3. Entre son mot de passe
  4. Clique sur "Enregistrer ma présence"
  5. Message de confirmation : "✓ Bienvenue ! Arrivée enregistrée à 08:30"

Admin en cours de journée :
  1. Ouvre "Présences du jour"
  2. Voit en temps réel qui est arrivé
  3. Consulte les statistiques :
     • Total de présences
     • Nombre d'arrivées
     • Nombre de départs
     • Nombre incomplets (pas encore partis)

Employé à la sortie :
  1. Rescanne le QR code
  2. Entre son ID et mot de passe
  3. Clique sur "Enregistrer ma présence"
  4. Message : "✓ Au revoir ! Départ enregistré à 17:00. Durée : 8.5h"

Admin en fin de journée :
  1. Ouvre "Rapport Présence"
  2. Filtre par date du jour
  3. Exporte en CSV pour traitement paie
  4. Imprime pour archives

🐛 DÉPANNAGE
─────────────────────────────────────────────────────────────────────────────────

Problème : Le QR code ne scanne pas
Solution :
  • Vérifiez que la URL est accessible depuis mobile
  • Testez avec : http://localhost/diagoma/admin/qrattendance/scan_page?token=xxxxx
  • Vérifiez que FontAwesome est chargé

Problème : "Employé non trouvé"
Solution :
  • Vérifiez que l'employé existe dans la table 'staff'
  • Vérifiez que le champ 'employee_id' est rempli
  • Vérifiez que l'employé est actif (is_active = 1)

Problème : "Mot de passe incorrect"
Solution :
  • Assurez-vous d'utiliser le bon mot de passe
  • Vérifiez que le champ 'password' existe dans staff
  • Réinitialisez le mot de passe de l'employé

Problème : Pas d'enregistrement
Solution :
  • Vérifiez que la table 'staff_attendance_qr' existe
  • Vérifiez les permissions MySQL
  • Vérifiez les logs PHP/MySQL

Problème : Cartes QR ne s'affichent pas dans le menu RH
Solution :
  • Vérifiez les permissions RBAC de l'utilisateur
  • Vérifiez que 'staff_attendance' > 'can_view' est accordé
  • Rafraîchissez la page (Ctrl+F5)

📊 DONNÉES COLLECTÉES
─────────────────────────────────────────────────────────────────────────────────

Table : staff_attendance_qr

Champs :
  • id                  (ID unique du scan)
  • staff_id            (ID de l'employé)
  • attendance_date     (Date du jour AAAA-MM-JJ)
  • arrival_time        (HH:MM:SS)
  • departure_time      (HH:MM:SS)
  • scan_date           (Timestamp complet)
  • status              (arrival/departure/complete)
  • notes               (Notes optionnelles)
  • created_at          (Date de création)
  • updated_at          (Date de mise à jour)
